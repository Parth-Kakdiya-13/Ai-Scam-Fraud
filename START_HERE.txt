📡 API ENDPOINTS

  Authentication:
    POST   /api/auth/register        Create account
    POST   /api/auth/login           Get JWT token
    POST   /api/auth/verify          Verify token

  Scanning:
    POST   /api/scan/message         Classify text → scam/safe/suspicious
    POST   /api/scan/url             Check URL → threat score
    POST   /api/scan/screenshot      OCR + classify image
    GET    /api/scan/history/:userId Get user scan history

  Community Reports:
    POST   /api/report               Report phone/UPI/domain
    GET    /api/report/fraud/:kind   Lookup entity
    GET    /api/report/list          List all frauds

  Health:
    GET    /api/health               Server status

See API_REFERENCE.md for complete curl examples!

🚀 PRODUCTION DEPLOYMENT

1. Push to GitHub
2. Deploy Backend (Render)
   • Connect GitHub repo
   • Set env variables: MONGO_URI, OPENAI_API_KEY, JWT_SECRET
   • Deploy → Renders to https://your-backend.onrender.com

3. Deploy Frontend (Vercel)
   • Connect GitHub repo
   • Set: NEXT_PUBLIC_API_URL=https://your-backend.onrender.com
   • Deploy → Renders to https://your-app.vercel.app

See DEPLOYMENT.md for step-by-step instructions!
